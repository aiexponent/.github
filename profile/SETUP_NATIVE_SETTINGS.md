# GitHub Organization Native Settings & Brand Customization Guide

This operational playbook details the setup and maintenance of native GitHub Organization features for [github.com/aiexponent](https://github.com/aiexponent).

Because GitHub reserves organization-level pinning, domain DNS challenges, and individual public membership to authenticated organization owners and members via the GitHub Web UI, follow the steps below to configure each native feature.

---

## 1. Pin 5 Flagship Repositories

Showcase the 5 flagship EU AI Act compliance tools front-and-center and remove internal housekeeping repositories from the top-level repository showcase.

### Steps:
1. Navigate to the organization front page: **[https://github.com/aiexponent](https://github.com/aiexponent)**.
2. Sign in as an organization owner (`apundhir`).
3. Click **"Customize your pins"** (or **"Pin repositories"**).
4. Select the **5 flagship repositories**:
   - [x] **`litmusai`** (Article 5 Prohibited Practices Screener)
   - [x] **`riskforge`** (Article 9 Risk Management File Generator)
   - [x] **`license-compliance-checker`** (Article 53 GPAI Model & Dependency Scanner)
   - [x] **`rag-benchmarking`** (Article 15 Accuracy & Robustness Harness)
   - [x] **`agentic-document-analyser`** (Article 9 Multi-Agent Document Pipeline)
5. Ensure **`.github`** is **unselected** so internal templates and profile assets do not occupy showcase slots.
6. Drag and reorder the cards if desired, then click **"Save pins"**.

## 2. Verify Organization Domain (`aiexponent.com`)

Domain verification establishes institutional authenticity and displays the green **"Verified"** checkmark badge next to `aiexponent.com` on the organization profile sidebar.

### Steps:
1. Navigate to Organization Domain Settings: **[https://github.com/organizations/aiexponent/settings/domains](https://github.com/organizations/aiexponent/settings/domains)**.
2. Under **"Verified and approved domains"**, click **"Add a domain"**.
3. Enter `aiexponent.com` and click **"Add domain"**.
4. GitHub will generate a unique DNS challenge:
   - **Type**: `TXT`
   - **Name / Host**: `_github-challenge-aiexponent`
   - **Value**: *(Unique verification string generated by GitHub)*
5. Log into your DNS provider (e.g. Cloudflare, AWS Route53, Namecheap, Google Cloud DNS) and add the `TXT` record.
6. Wait 1–2 minutes for DNS propagation, return to the GitHub settings page, and click **"Verify"**.
7. The green **"Verified"** badge will immediately activate on the organization sidebar.

## 3. Enable Public Membership Visibility

By default, GitHub sets organization membership visibility to "Private". Changing this to "Public" shows founder and maintainer profile avatars under the **"People"** section on the organization front page, establishing credibility and active ownership.

### Steps:
1. Navigate to the People management page: **[https://github.com/orgs/aiexponent/people](https://github.com/orgs/aiexponent/people)**.
2. Locate your member account (`apundhir`).
3. In the **"Organization visibility"** column, click the dropdown currently set to **"Private"** and select **"Public"**.
4. Immediately, your profile avatar and link will display on **[https://github.com/aiexponent](https://github.com/aiexponent)** under "People".

5. GitHub will immediately display the card in the preview box and unfurl it whenever repository URLs are shared.
